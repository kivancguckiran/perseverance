# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to provide a harassment-free community experience for everyone,
regardless of age, body size, disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socioeconomic status,
nationality, personal appearance, race, religion, or sexual identity and orientation.

Positive behavior includes empathy, respect for differing views, constructive
feedback, accountability, and a focus on what is best for the community. Harassment,
trolling, insults, sexualized conduct, personal or political attacks, and publishing
private information without permission are unacceptable.

Project maintainers may remove, edit, or reject contributions and interactions that
violate these standards. This code applies in all project spaces and whenever someone
officially represents the project in public.

Report abuse or harassment to **kivancguckiran@gmail.com**. Reports will be reviewed
promptly, fairly, and with respect for the reporter's privacy. Enforcement follows the
Contributor Covenant community-impact guidelines.
