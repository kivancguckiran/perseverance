# Raw Sources

Bu dizin yalnız repo dışından alınan immutable kaynak snapshot'ları içindir.

- Yeni kaynakları `YYYY-MM-DD-kisa-ad.ext` biçiminde ekle.
- Mümkünse yanında origin URL, retrieved date ve SHA-256 içeren bir `.metadata.json` tut.
- Mevcut snapshot'ı değiştirme; düzeltme veya yeni sürüm için yeni dosya ekle.
- Secret, credential, kişisel veri, `.runtime` verisi ve lisansı snapshot almaya izin vermeyen tam metinleri ekleme.

Repo içi kod ve belgeler buraya kopyalanmaz; `sources/index.md` üzerinden yerinde referanslanır ve Git revision ile izlenir.
